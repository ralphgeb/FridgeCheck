# Plume Avios Wallet

A household Avios and BA Club tracker. Live at https://ralphgeb.github.io/FridgeCheck/

- **Wallet**: everyone's Avios, Tier Points progress to the next tier, and vouchers with expiry countdowns, plus "best use right now" suggestions.
- **Redeem**: every destination from London you can reach with your pooled (or individual) Avios by cabin, peak/off-peak, travellers and Companion Voucher, plus an upgrade-with-Avios calculator.
- **Earn**: a goal planner (how many months of card spend to reach a trip) and the main ways to earn more Avios.
- **Trips**: a boarding-pass log of past trips with distance flown and Avios earned and spent.
- **Settings**: add up to 7 accounts, vouchers, Household pooling, backup and restore.

British Airways has no public API for third-party apps, so balances are entered by hand and stored only in the browser. Plume never asks for a BA password. Reward prices are indicative. Not affiliated with British Airways or Avios.

Single static file (`index.html`), no build step.
